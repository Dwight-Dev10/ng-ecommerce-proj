# E-Commerce Application

A full-stack e-commerce project built to explore
modern application development and architecture.

## Projects

- `client/` — Angular 21 frontend
- `server/` — ASP.NET Core Web API

## Getting Started

See the README inside each project directory
for application-specific setup instructions.

## Architecture

The Angular client communicates with the ASP.NET Core
API over HTTP. Each application has its own dependencies,
build process, and configuration.
